# LUMI — operational corpus

Facts about the LUMI supercomputer (CSC, Kajaani) that shape how we move data to it and run on it. Collected from LUMI documentation and the 2025–2026 LUMI training courses. Companion to [`corpus/irbene/`](../irbene/README.md); source keys for both live in [`corpus/irbene/sources.md`](../irbene/sources.md) §"Compute and network infrastructure".

**Rule:** same as the Irbene corpus — every statement carries a source key. Hardware sizes, quotas and billing are in `docs/virac/RFI_LUMI_FINDINGS.md` §4–5; this file holds the operational detail that does not fit a findings doc.
